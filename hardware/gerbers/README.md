# Gerbers — not yet generated

This folder is a placeholder. Gerber files require a routed PCB (copper
layout), which does not exist yet — only the schematic (`hardware/kicad/`)
has been completed so far.

Once PCB layout/routing is done (by Süalp, TA4HCK), gerbers can be exported
from KiCad (`File → Fabrication Outputs → Gerbers`, or `kicad-cli pcb
export gerbers`) and placed in this folder.
